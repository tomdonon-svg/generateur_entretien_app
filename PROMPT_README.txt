Le prompt complet et dynamique est généré directement par app.py
dans l'onglet « Générer des questions ».

Il impose notamment :
- JSON uniquement ;
- réponse attendue détaillée ;
- mémo interviewer détaillé ;
- relances ;
- thèmes ;
- scénario ;
- langages ;
- spécialités ;
- niveaux ;
- technologies ;
- durée estimée.
