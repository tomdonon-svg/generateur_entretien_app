Contexte : Développement d’une application générant un questionnaire technique pour un entretien d’embauche. Les exigences sont listés dans la suite du message. 

Acteur : agis comme un développeur, architecte, travaillant dans le logiciel. 
 Demande : Créer une application permettant de générer un questionnaire technique pour un entretien d’embauche.  
 Règles : il faut respecter les exigences 

Relecture : Relie à la fin ton programme pour vérifier l'implémentation des exigences 

  

Exigences : 

- Le programme doit être en python et déployable sur streamlit 

- Chaque question doit avoir une partie réponse attendu détaillée 

- Chaque question doit avoir une partie mémo interviwer, permettant à la personne en charge de l'entretien d'avoir des rappel des réponses attendu plus en détails, afin que celui-ci ne soit pas obligé de réviser les différents points qu'il aurait pu oublier 

- Chaque question doit avoir une partie relance 

- Le programme doit regrouper les questions par sujet/thématique, si possible avec un scénario/contexte commun. 

- Le choix des questions doit être fait via les critères saisie sur une IHM suivantes :  

  - les langages  

  - la spécialité 

  - le niveau 

  - la durée 

  - les technologies 

  - le nombre de questions 

- Le programme ne doit pas faire de requête à chatGPT.   

- La création des questions doit se faire de façon indépendante en renseignant un prompt dans ChatGPT.   

- Le programme doit fournir les ressources pour réaliser ce prompt du mieux possible pour respecter les éxigences. L’attendue est un fichier JSON.  

- Le programme doit permettre à l’utilisateur de rajouter des questions via un ou plusieurs fichier JSON.    

- Le programme doit permettre de télécharger le questionnaire en docx et en markdown
